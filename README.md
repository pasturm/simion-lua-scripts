This is a collection of custom Lua scripts for the ion optics simulation program 
[SIMION](http://simion.com/). 

There are enhanced versions of SIMION's
existing Lua scripts as well as additional useful tools.

* stl2palib.lua: STL to SIMION potential array conversion library
* tuner: voltage optimization library based on design of experiments and response surface modelling methods
* functions_pst.lua: statistics and other utility functions
* gnuplot_pst.lua: enhanced gnuplot library
* conversion tools to import fields from other simulation software (OpenFOAM, COMSOL, Sparta)
* and many more...
